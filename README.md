Beeboard – Project & Task Management Platform
📌 Overview
Beeboard is a task and project management platform built to help both companies and individuals organize their work efficiently.
This project was part of my Front-End Developer internship at SIT Solutions – Al-Madinah, where I contributed to designing UI components, improving user experience, and implementing core front-end logic.

🛠️ Technologies Used
HTML
CSS
JavaScript
Bootstrap
AJAX (GET & POST)
🎯 Key Features I Developed
Built responsive and clean UI components aligned with the platform’s design system.
Implemented dynamic sections for managing tasks, deadlines, and categories.
Integrated AJAX calls to fetch and update project data without reloading the page.
Improved user navigation and usability based on feedback from the development team.
Optimized structure for scalability and future back-end integration.
